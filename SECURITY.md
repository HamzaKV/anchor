# Security

## Reporting a vulnerability

Open a [GitHub Security Advisory](https://github.com/HamzaKV/anchor/security/advisories/new) or email hamzakv333@gmail.com. Don't open a public issue for undisclosed vulnerabilities.

Include what you found, how to reproduce it, and its impact. You should get a response within a few days.

## Supported versions

Only the latest published version on npm receives security fixes.

## Note on checklist content

`anchor` checklists are plain markdown files intended to be committed to your repo. Don't paste real secret values (API keys, passwords, tokens) into checklist items — they'll be stored in plaintext in version control.
